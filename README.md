## Overview

**SecurePass360 Pro** is a Windows password manager engineered by **Vincenzo Chieppa (SoftEdition / MZGuard)** specifically to defend against modern **infostealer malware** (such as RedLine, Raccoon, Lumma, and browser credential dumpers). Unlike browser-resident password managers that leave secrets exposed in predictable SQLite databases or unprotected memory, SecurePass360 Pro isolates credentials inside an encrypted desktop vault.

## Security Architecture

* **Anti-Infostealer Isolation:** Eliminates plaintext and easily decryptable browser-stored passwords targeted by commodity stealers.
* **Just-In-Time (JIT) Decryption:** Secrets remain encrypted at rest and are decrypted only at the exact moment of use inside protected memory.
* **Secure Browser Bridge:** Safely supplies credentials to web browsers without exposing the underlying master database.
* **Local-First Control:** Keeps credential management under strict local ownership.
